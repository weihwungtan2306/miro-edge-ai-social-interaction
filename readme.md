# Edge AI Acceleration on the MiRo Robot for Enhanced Social Interaction

This project investigates how Edge AI acceleration can improve the real-time social interaction capabilities of the MiRo robot.

## Current Stage

- Drafting introduction
- Reviewing literature
- Reviewing state-of-the-art face and emotion recognition models
- Setting up development environment
- Preparing for MiRo/ROS integration

## Possible Models

- MediaPipe Face Detection / BlazeFace
- YOLOv8n
- MobileNet SSD
- Lightweight facial emotion recognition model
- TensorFlow Lite speech command model

## Planned Evaluation

- Inference latency
- Frames per second
- CPU/RAM usage
- Model accuracy
- End-to-end robot response time
- User-perceived responsiveness/naturalness if applicable
